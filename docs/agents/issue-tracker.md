# Issue tracker: GitHub

Issues and specs live in MrWaip/game25 on GitHub.
Use the gh CLI with --repo MrWaip/game25.

- Publish a spec by creating an issue.
- Read issues with their comments and labels.
- Pass multiline issue bodies and comments through --body-file.
- Apply triage labels using docs/agents/triage-labels.md.
- When fetching a ticket, use gh issue view <number> --comments.

PRs as a request surface: no.
