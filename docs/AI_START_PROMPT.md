# Контекст для новой сессии

Работаем над game25: несколько браузерных игр на общем самописном TypeScript
Canvas ECS. Сейчас есть платформер (`src/games/jumper`) и roguelike tower defense
(`src/games/defense`). Целевой экран defense — вертикальный мобильный WebView.

Перед изменениями прочитай `AGENTS.md` и `docs/ARCHITECTURE.md`. Актуальные
спецификации находятся в GitHub Issues; правила работы с ними — в
`docs/agents/issue-tracker.md`.

Игровые механики, ассеты, темы и тестовые помощники принадлежат конкретной игре.
Общие модули не импортируют игры, игры не импортируют друг друга. Это проверяется
линтером и тестами изоляции. Не возвращай платформер в общие папки при исправлениях.

При работе с Canvas-интерфейсом используй существующие типизированные модули
`src/render/ui`; описание интерфейса и жизненного цикла — в `docs/canvas-ui.md`.
Палитра общая, назначения цветов находятся только в общих и игровых `theme.ts`.

Проверяй поведение через реальную сессию defense или harness платформера.
Перед завершением изменений запускай `npm run smoke`; для браузерных изменений
также `npm run test:browser` и `npm run build:site`.
