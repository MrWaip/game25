## Движущиеся платформы

### Цель
Реализовать механику движущихся платформ, чтобы игрок сохранял скорость движения платформы при стоянии на ней.

### Подход
1. **Добавить скорость платформам**
   - Расширить `PlatformComponent` или добавить `VelocityComponent` для движущихся платформ
   - Добавить тип платформы "moving" или флаг `isMoving` в `PlatformComponent`

2. **Перемещать платформы**
   - Расширить `PhysicsSystem` для обработки платформ с `VelocityComponent`
   - Обновлять позицию платформы каждый кадр: `position += velocity * dt`

3. **Передавать скорость платформы игроку**
   - В `PhysicsSystem` при коллизии игрока с платформой сверху (normal[1] > 0):
     - Добавлять скорость платформы к позиции игрока каждый кадр
     - ИЛИ добавлять скорость платформы к скорости игрока (менее предпочтительно)
   - Использовать подход с добавлением к позиции для более точной "привязки" игрока к платформе

### Файлы для изменения
- `src/components/platformComponent.ts` - добавить поддержку скорости
- `src/entities/platform.ts` - добавить создание движущихся платформ
- `src/systems/physicsSystem.ts` - обработать движение платформ и передачу скорости игроку
- `src/systems/platformSystem.ts` - возможно, добавить логику движения

### Детали реализации
- Когда игрок стоит на движущейся платформе (проверка через `CollidedComponent.isGrounded` и `normal[1] > 0`), нужно определить, какая именно платформа под игроком
- Получить `VelocityComponent` этой платформы
- Каждый кадр добавлять `platformVelocity * dt` к позиции игрока
- Учесть случай, когда игрок прыгает с платформы - не применять скорость платформы
